# Odd Souls Dates — лендинг

Лендинг приложения **Odd Souls Dates**, раздаётся по адресу
https://oddsouls.github.io/oddsouls/ (подкаталог `/oddsouls/` пользовательского
GitHub Pages-сайта `oddsouls.github.io`).

Содержимое (`index.html`) обновляется автоматически скриптом публикации
APK из репозитория приложения: при каждой сборке подставляются версия,
размер, SHA-256 и ссылка на свежий APK.

Исходный код приложения — приватный. Сами APK-сборки раздаются из отдельного
репозитория [odd-souls-dates-releases](https://github.com/oddsouls/odd-souls-dates-releases).

## Скачать

- 🌐 Страница загрузки: https://oddsouls.github.io/oddsouls/
- 📦 Последний APK: [Releases](https://github.com/oddsouls/odd-souls-dates-releases/releases/latest)

## Установка

1. Скачайте APK-файл на Android-устройство.
2. В настройках разрешите установку из неизвестных источников.
3. Откройте файл и установите.

## Проверка целостности

Сравните SHA-256 файла с указанным на странице релиза:

```bash
sha256sum app-release.apk
```
